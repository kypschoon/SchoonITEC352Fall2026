# This program models a Snake with four attributes: name, location,
# length, and is_venomous. The Snake class is defined in
# the constructor. Two methods interact with each object:
# grow_snake() asks for a positive number of feet and adds it to
# length, repeating on invalid input; get_summary() returns a
# sentence describing the snake.

# Main_schoon.py imports Snake, creates three objects (Python,
# Cobra, Cottonmouth), calls both methods on each, and prints the results.

# How to run:
# python main_schoon.py
